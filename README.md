# PC Parts Race

A simple Roblox game where players collect PC parts to earn points. This game is designed for educational purposes and to demonstrate basic Roblox scripting concepts. Players can collect various PC parts scattered around the game world, each collection awarding them points. The game features a user interface to display the player's current points, and it includes a leaderboard system to track and display the points of all players.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Click on "File" in the top menu and select "Open Model".
4. Navigate to the downloaded project files and select the `.rbxl` or `.rbxlx` file.
5. Click "Open" to load the project into Roblox Studio.

## Use

1. In Roblox Studio, ensure the game is loaded.
2. Click on "Play" in the top menu to start the game in test mode.
3. Players can join the game using the Roblox client.
4. Players will see PC parts spawn in the game world.
5. Click on the PC parts to collect them and earn points.
6. The player's points will be displayed on the screen and updated in real-time.
